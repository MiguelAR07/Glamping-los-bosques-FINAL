# Glamping los bosques

Este proyecto es una interfaz moderna para un sistema de glamping, construida con React, TypeScript y Tailwind CSS.

## Características

- Diseño premium y responsive.
- Secciones interactivas para cabañas.
- Integración de reserva (en desarrollo).

## Tecnologías

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Construcción

```bash
npm run build
```
